# LaTeX Style Files

These are the LaTeX style files that are developed in this repo.

| File | Description |
| --- | --- |
| [`src2listing.sty`](src2listing.sty)| Styles and commands for source code listings. Basically a wrapper around the `listings` package that uses `tcolorbox` for styling. |
| [`src2report.sty`](src2report.sty) | Environments and commands for creating exam reports. Builds on the `src2listing` package. |
